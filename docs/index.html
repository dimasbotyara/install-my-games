01 / ПОДГОТОВКА

Прежде чем начать.

01 — 09

Пара важных вещей, которые стоит знать до первой команды.

!
Используй только там, где это разрешено

Проект создавался для ALT Linux Education. Лаунчер скачивает и запускает код из репозиториев, создаёт файлы в домашней папке и меняет настройки оболочки. Изучи код и получи разрешение владельца или администратора компьютера. Не запускай скрипты, которым не доверяешь.

✓
Linux-компьютер

Основная цель — ALT Linux Education. Для других дистрибутивов названия пакетов могут отличаться.

✓
Python 3 и Git

Также нужны работающие venv и pip. Для онлайн-установки потребуется доступ к GitHub и индексам пакетов.

✓
Немного свободного места

Для репозиториев и отдельного виртуального окружения каждой игры.

Проверить инструменты можно в терминале:

ТЕРМИНАЛ
python3 --version
git --version
python3 -m pip --version

Если venv не работает, в ALT Linux могут понадобиться пакеты python3-module-pip и python3-module-venv. Устанавливай системные пакеты только с разрешения администратора.

02 / ПЕРВЫЙ ЗАПУСК

Установка.

02 — 09

Выбери удобный способ. Обе команды сначала сохраняют файлы на диск — их можно изучить до запуска.

01

Клонировать репозиторий

Рекомендуемый способ: рядом будут и лаунчер, и мастер подготовки флешки.

РЕКОМЕНДУЕМ
BASH / LINUX
git clone https://github.com/dimasbotyara/install-my-games.git
cd install-my-games

Изучи launch.py, прежде чем запускать его. Затем выполни команду ниже.

ПЕРВЫЙ ЗАПУСК
python3 launch.py
02

Скачать через curl

Только лаунчер. Для подготовки флешки нужны оба файла — смотри ниже.

BASH / LINUX
mkdir -p botyara-games && cd botyara-games
curl -fL -o launch.py https://raw.githubusercontent.com/dimasbotyara/install-my-games/main/launch.py

Скачивание с main получает текущую версию, а не закреплённый релиз. Перед запуском проверь содержимое файла, например less launch.py, а затем выполни:

ПЕРВЫЙ ЗАПУСК
python3 launch.py
01

Введи пароль. Лаунчер запросит его при входе; ввод не отображается. Для просмотра версии и справки пароль не нужен.

02

Подтверди установку игр. При первом обычном запуске лаунчер предложит скачать отсутствующие игры. Или выбери i в меню.

03

Выбери игру. Введи номер или имя в меню. При необходимости лаунчер попросит выбрать точку входа.

✳
Запустить позже

При обычном запуске лаунчер копируется в ~/.config/systemd-backup/ и добавляет alias dimasbotyara в настройки оболочки. Открой новый терминал или выполни source ~/.bashrc, если используешь bash.

03 / БЕРЁМ С СОБОЙ

Подготовка флешки.

03 — 09

Подготовь носитель на компьютере с интернетом, чтобы потом установить игры на Linux-ПК без сети.

!
Проверь путь к носителю

Мастер не форматирует диск, но записывает и обновляет файлы в папке BOTYARA-GAMES. Убедись, что выбран нужный диск и на нём достаточно места. Сделай резервную копию важных данных.

1. Узнай параметры целевого Linux-ПК

Именно под этот компьютер будут подбираться wheel-файлы. Версию Python, архитектуру и glibc можно узнать заранее:

ЦЕЛЕВОЙ LINUX-ПК
python3 --version
uname -m
ldd --version

2. Запусти мастер на компьютере с интернетом

Нужны Python 3 с pip и Git. Если репозиторий уже клонирован, открой его папку и запусти:

LINUX / WINDOWS
python3 prepare_usb.py

В Windows используй py prepare_usb.py. При необходимости сначала клонируй репозиторий командой из раздела установки.

А можно подготовить через curl? +

Да, скачай оба файла в одну папку на Linux: prepare_usb.py импортирует launch.py.

BASH / LINUX
mkdir -p botyara-games && cd botyara-games
curl -fL -o launch.py https://raw.githubusercontent.com/dimasbotyara/install-my-games/main/launch.py
curl -fL -o prepare_usb.py https://raw.githubusercontent.com/dimasbotyara/install-my-games/main/prepare_usb.py

Проверь оба скачанных файла, затем запусти мастер:

ЗАПУСК МАСТЕРА
python3 prepare_usb.py

3. Ответь на вопросы мастера

01

Выбери обнаруженный съёмный диск или введи путь к смонтированной флешке вручную.

02

Если BOTYARA-GAMES уже есть, мастер спросит, обновлять ли её. Для нового ПК без сети выбери и репозитории, и wheel-файлы.

03

Укажи одну или несколько версий CPython (например, 3.10, 3.12) или введи все, чтобы скачать наборы для 3.10–3.14. Выбери общую архитектуру и минимальную версию glibc.

Мастер использует интерфейс curses в цветах Gruvbox Dark, а если терминал его не поддерживает — обычные текстовые вопросы. Чтобы позже обновить флешку, запусти bash update_repos_usb.sh на Linux с интернетом. Скрипт должен лежать рядом с launch.py на флешке: он скачает более новую версию лаунчера, если она есть в main, и синхронизирует репозитории по её списку. Wheels и установленная на ПК копия лаунчера не изменятся.

✳
Linux wheels даже на Windows

Мастер подбирает бинарные Linux wheels и универсальные пакеты для каждой версии Python. Точная patch-версия Python и версия ядра неизвестны, поэтому проверь готовые наборы на целевом ПК.

04 / БЕЗ ИНТЕРНЕТА

Офлайн-установка.

04 — 09

Флешка подготовлена? Подключи её к Linux-ПК и запускай именно копию лаунчера с носителя.

▣ СОДЕРЖИМОЕ ФЛЕШКИ
BOTYARA-GAMES/
├── launch.py
├── repos/                 ← копии игр
│   ├── botyarapong/
│   └── ...
└── wheels/                ← пакеты для каждой игры
    └── botyarapong/
        ├── cp310/             ← Python 3.10
        └── cp312/             ← Python 3.12

Подставь реальный путь к флешке вместо примера:

ЦЕЛЕВОЙ LINUX-ПК
python3 /путь/к/флешке/BOTYARA-GAMES/launch.py --install

После ввода пароля лаунчер скопирует доступные репозитории и автоматически выберет набор wheels по версии Python виртуального окружения игры. Зависимости установятся без обращения к индексу пакетов. Старые наборы без подпапок по версиям тоже поддерживаются.

!
Что не делает флешка

Она не устанавливает системный Python, pip, venv, графическую среду или нативные библиотеки ОС. Не для каждого пакета существует подходящий wheel. Прямые ссылки в requirements и метаданных wheel в офлайн-режиме отклоняются.

Установленная на ПК копия лаунчера не ищет подключённую флешку автоматически. Для офлайн-установки и восстановления запускай файл launch.py с флешки.

05 / УПРАВЛЕНИЕ

Знакомство с меню.

05 — 09

Никаких сложных команд: большая часть действий доступна прямо в лаунчере.

КЛАВИШАЧТО ПРОИЗОЙДЁТ
1..NЗапустить игру по номеру или введи её имя
iУстановить или обновить игры
aСинхронизировать реестр с папками игр
dУдалить выбранную игру с подтверждением
rВосстановление окружений и удаление следов
sПосмотреть характеристики компьютера
uВручную проверить обновление лаунчера
qВыйти из лаунчера

Как запускаются игры?

Оконные приложения на pygame или CustomTkinter (например, nnn-countdown) отделяются от лаунчера: игра продолжает работать самостоятельно. Если игра сразу завершилась, вывод ошибки остаётся в терминале. Веб-приложения, например alchemy-matcher и botyaracloud на Flask, запускаются в том же терминале с логом. Меню анимаций cli-anims тоже остаётся в терминале: из него можно выйти клавишей Q. При завершении приложения или остановке через Ctrl+C лаунчер очищает терминал и закрывается. Если найдены и GUI-, и веб-зависимости, приоритет у оконного режима.

Полезные аргументы

КОМАНДНАЯ СТРОКА
python3 launch.py --help
python3 launch.py --version
python3 launch.py --specs
python3 launch.py --install
python3 launch.py --sync
python3 launch.py --update
python3 launch.py botyarapong

--help, --version и --specs не требуют пароль. Остальные действия защищены паролем.

06 / ПОД КАПОТОМ

Файлы и настройка.

06 — 09

Немного о том, что происходит после запуска, и где искать результаты.

01

Папка игр и реестр

Игры, .registry.json и установленная копия скрипта находятся в ~/.config/systemd-backup/. Реестр синхронизируется с папками при запуске.

02

Зависимости и точка входа

Для каждой игры создаётся .venv. При наличии используется requirements.txt, иначе сканируются импорты. Порядок поиска запуска: run.py → app.py → main.py → единственный Python-файл → ручной выбор.

03

Список репозиториев

По умолчанию он задан в REPO_LIST внутри launch.py. Можно временно выбрать несколько игр переменной окружения:

BASH
BOTYARA_REPOS="botyarapong,botyaragames" python3 launch.py

Переменная также работает с prepare_usb.py. Имена берутся из аккаунта GitHub, указанного в скрипте.

04

Настройки оболочки

При обычном запуске создаётся alias в ~/.bashrc и ~/.zshrc. В bash также добавляются HISTIGNORE и HISTCONTROL; они влияют на историю команд. Проверь эти изменения перед использованием.

!
Пароль — не защита системы

В скрипте хранится солёный хеш, а не сам пароль. Это простое ограничение доступа к меню: слабый пароль можно подобрать, а человек с доступом к файлу может обойти проверку. Не используй его для защиты важных данных.

07 / НУЖНА ПОМОЩЬ?

Если что-то пошло не так.

07 — 09

Не переживай. Вот несколько частых ситуаций и что можно попробовать.

Не создаётся виртуальное окружение +

Проверь python3 --version и наличие модулей venv и pip. В ALT Linux могут понадобиться python3-module-pip и python3-module-venv. Если окружение создано без pip, пакеты в него не установятся. Обратись к администратору.

Не находится подходящий wheel +

Сверь версию CPython, архитектуру и glibc целевого ПК с выбранными при подготовке флешки. Некоторые пакеты не публикуют совместимые бинарные сборки. Подготовь набор снова и проверь его на целевой машине.

Флешка не появилась в списке +

Убедись, что она подключена и смонтирована. На Linux мастер использует lsblk, на Windows — типы дисков. Если автоматическое обнаружение не помогло, введи существующий путь к флешке вручную и внимательно проверь его.

Игра не запускается после установки +

Посмотри ошибки в терминале и итоги установки. В меню r можно пересоздать виртуальное окружение игры. Для восстановления без сети запускай лаунчер с флешки, на которой есть совместимые wheels.

GitHub недоступен, но игры уже установлены +

Установленные игры можно запускать без интернета. Для новой установки подготовь копии репозиториев и wheels на флешке. Когда сеть доступна, лаунчер предпочитает GitHub, а копии на флешке использует как резервный источник.

Команда dimasbotyara не найдена +

Alias добавляется при обычном запуске, а не при --install. Открой новый терминал или выполни source ~/.bashrc в bash. Альтернативно запусти python3 ~/.config/systemd-backup/launch.py.

08 / НАВОДИМ ПОРЯДОК

Восстановление и удаление.

08 — 09

Если понадобится начать заново, у лаунчера есть инструменты для этого.

01 / ПОЧИНКА

Пересоздать окружение

В меню r выбери нужные игры или все сразу. Их .venv удалятся и будут собраны заново вместе с зависимостями.

02 / УДАЛЕНИЕ

Удалить данные с ПК

В меню r выбери «удалить все следы» и подтверди действие словом УДАЛИТЬ. Игры, реестр, копия скрипта и добавленные настройки будут удалены. Флешка не затрагивается.

!
Удаление необратимо

Папки игр будут удалены вместе с находящимися в них файлами. Сохрани нужные данные заранее и внимательно проверь, что удаляешь.
